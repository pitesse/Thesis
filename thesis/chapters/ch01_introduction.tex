\section{Context and Motivation}

Formula 1 pit-wall decisions are streaming decision-support decisions: the same driver-lap can be judged differently depending on evolving race context, track status, and rival dynamics. A reproducible research setup therefore needs event-time processing semantics, replayable logs, and explicit state handling \citep{akidau2015dataflow,carbone2015flink,kreps2011kafka}.

This thesis implements that setup as a replay-to-evaluation pipeline:
\begin{center}
FastF1 history $\rightarrow$ Kafka replay $\rightarrow$ Flink strategy outputs $\rightarrow$ JSONL/Parquet data lake $\rightarrow$ contract-based evaluation.
\end{center}

\section{Research Goal and Scope}

The goal is to compare three decision paradigms under one shared protocol:
\begin{itemize}
    \item \textbf{Flink Strategy Engine}: deterministic stream-time strategy rules.
    \item \textbf{Batch XGBoost}: offline learning with race-sequential OOF predictions \citep{chen2016xgboost,roberts2017cvstructured}.
    \item \textbf{MOA Online Learner}: prequential test-then-train stream learner \citep{bifet2010moa}.
\end{itemize}

Headline scope:
\begin{itemize}
    \item seasons 2022--2025,
    \item shared truth universe \texttt{canonical\_sde\_truth},
    \item main lens \texttt{clean\_actionable},
    \item contracts \texttt{pit\_any\_h2} and corrected \texttt{pit\_success\_h2}.
\end{itemize}

\section{Contracts Used in the Thesis}

\subsection{\texttt{pit\_any\_h2}}
At lap $k$, predict whether any eligible pit event occurs soon (horizon $H=2$).

\subsection{\texttt{pit\_success\_h2} (corrected contract)}
At lap $k$, predict whether a successful evaluated pit occurs in strict future horizon $[k{+}1,k{+}2]$.
\begin{itemize}
    \item Positive: matched pit outcome \texttt{SUCCESS\_*} or \texttt{OFFSET\_ADVANTAGE}.
    \item Negative: no pit in horizon, or matched \texttt{FAILURE\_*}/\texttt{OFFSET\_DISADVANTAGE}.
    \item Excluded from clean train/eval: unresolved/weather/unmapped outcomes.
\end{itemize}

Operational rule used in this thesis:
\begin{itemize}
    \item positive recommendation with no pit in horizon is a false positive (not excluded).
\end{itemize}

\section{Research Questions}

\textbf{RQ1.} Can the Flink Strategy Engine be frozen as a fair deterministic baseline for 2022--2025 replay?

\textbf{RQ2.} Under leakage-safe race-sequential OOF evaluation, how do Batch XGBoost profiles compare against Flink Strategy Engine on \texttt{pit\_any\_h2} and \texttt{pit\_success\_h2}?

\textbf{RQ3.} Under prequential evaluation, does the MOA Online Learner provide competitive ranking and selected operating points under the same truth contract?

\textbf{RQ4.} How much of observed behavior is model signal versus threshold-policy choice?

\section{Contributions}

\begin{itemize}
    \item A reproducible replay-to-evaluation pipeline grounded in executable code and auditable artifacts.
    \item A corrected contract definition for \texttt{pit\_success\_h2} with strict operational scoring.
    \item A fair three-way comparison (Flink Strategy Engine, Batch XGBoost, MOA Online Learner) under shared universe and lens.
    \item A metric framework that separates:
    \begin{itemize}
        \item strict operational precision (apples-to-apples),
        \item successful event coverage (recall-like),
        \item matched-pit success rate (diagnostic only).
    \end{itemize}
\end{itemize}
